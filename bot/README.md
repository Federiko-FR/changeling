Данный бот имеент 3 обработчика сообщения.  
/start - отправляет пользователю приветсвенное сообщение.  
/history - отправляет пользователю его последние 5 сообщений с указанием даты отправки.  
Каждое другое сообщение записывается в базу данных. Также отправляется запрос на HUGGINGFACE к модели DeepSeek-R1, после чего приходит ответ.  
Для запуска бота необходимо создать файл .env аналогичный .env_sample в директории bot в котором указать следующие параметры:
TOKEN - токен вашего бота.  
POSTGRES_DB - имя базы данных.  
POSTGRES_USER - имя пользователя бд.  
POSTGRES_PASSWORD - пароль от бд.  
TUNA_URL - URL полученный при выполнении команды tuna http 8081.  
HUGGINGFACE_API_TOKEN - токен выданный на сайте HUGGINGFACE.CO.  
После чего запустить выполнить команду sudo docker compose up
